# Архитектура BitRate

BitRate — синхронное FastAPI-приложение с тремя связанными ресурсами: **Project → Audit → Finding**. Отчёт вычисляется по аудиту и его замечаниям, отдельно не хранится.

## Слои

- `api/routes`: URL, параметры, HTTP-статусы и модели ответа.
- `schemas`: Pydantic-валидация запросов и структура ответов.
- `services`: правила проекта, анализа и изменения статуса замечаний.
- `repositories/memory.py`: три словаря по UUID и общий `RLock` для связанных изменений.
- `api/error_handlers.py`: перевод предметных ошибок в 404/409/422.

Хранилище создаётся в `create_app()`. Поэтому отдельные экземпляры приложения не делят данные. Хранение временное: после перезапуска данные исчезают; для учебного задания достаточно одного процесса сервера.

## Три сценария

1. **Проект:** создать, найти, переименовать, удалить. Имена уникальны без учёта регистра; удаление каскадно удаляет аудиты и замечания.
2. **Аудит:** выбрать существующий проект, отправить Python-текст или характеристики элементов интерфейса. Анализ выполняется без запуска кода; аудит и замечания записываются вместе. Повторные аудиты создают историю.
3. **Замечания и отчёт:** фильтровать проблемы, закрывать их с комментарием, открывать повторно и смотреть начальную и текущую оценки. Повторная установка того же статуса даёт 409.

Оценка: `max(0, 100 - сумма штрафов)`; low=5, medium=10, high=20, critical=30. Начальная оценка считает все замечания, текущая — только открытые. Ручное закрытие не меняет исходный результат аудита.

Границы версии: нет базы данных, авторизации, frontend, загрузки Git-репозиториев, URL или внешнего AI. Дизайн проверяется только по переданным свойствам элементов.
